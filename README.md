# Vs School

Vs School is a tri-lingual Malaysian school safety app prototype built with React + Express + Vite.

## Features
- Chinese / English / Bahasa Melayu UI
- Student / Teacher / Admin roles
- Login + registration flow
- Report submission and case detail views
- AI chat with safety escalation and resource suggestions
- Notifications and settings
- Admin analytics dashboard
- Backend mock API for local development

## Quick start

```bash
npm install
npm run dev
```

Then open:
- Frontend: http://localhost:5173
- Backend: http://localhost:3001
